# Windows Server Infrastructure Setup in Virtual Lab Environment

## Project Overview
This project demonstrates a basic Windows Server infrastructure lab setup in a virtual environment using VMware Workstation Pro.

## Technologies Used
- VMware Workstation Pro
- Windows Server
- Active Directory Domain Services (AD DS)
- DNS
- File Server

## Key Tasks Performed
- Created and configured virtual machines
- Configured Active Directory for domain and user management
- Set up DNS services for name resolution
- Configured File Server for shared resource sharing
- Practiced VM management and connectivity troubleshooting

## Skills Demonstrated
- Windows Server Administration
- Virtualization
- Active Directory
- DNS Configuration
- File Server Management
- Troubleshooting
